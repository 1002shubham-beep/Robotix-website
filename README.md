# Robotics Landing Page

A responsive landing page for **ROBOFEST'26**, presented by ROBOTiX Club, NIT Raipur. The design uses a dark technical theme with bright green and cyan accents to highlight robotics, events, and the club.

## Live website

https://1002shubham-beep.github.io/Robotix-website/

If this link does not open, check the published URL under **Repository Settings → Pages**.

## Features

- Responsive navigation with a mobile menu
- Hero section introducing ROBOFEST'26
- About, events, sponsors, and registration information
- Robotics event cards and visual effects
- Responsive layout for desktop and mobile screens

## Built with

- HTML
- CSS
- JavaScript

## Run locally

Download or clone this repository, then open `index.html` in a web browser.
